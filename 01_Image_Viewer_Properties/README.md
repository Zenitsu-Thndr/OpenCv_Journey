## Description

This is the Starting of my openCv journey and in this project,
i have learnt how to show, modify, even crop and adding elements on the image using simple openCv functions.




# What does this project do?

This project simply show and image using openCv with modifications and a text on image which displays the information of that image! Anyone can replace the image path with your image also, anyone can change the properties by changing some numbers! ###



# Which libraries are used in this project!
openCv : for image processing
os : handling paths and generate some information
Numpy(not directly but internally opencv uses it) : handling image and form them into array so openCv uses them array for image processing 



# How to use ?
First create a python virtual environment using this command in terminal :  Python 3.11.9 -m venv .venv
We have used a specific version(Python 3.11.9) for python in this project so first you need to download this version from python.org

Second press ctrl+shift+p on windows then select python intereptor and then click on your created .venv
Now you have your own virtual environment

Third run this command in terminal : pip install -r requirments.txt
It will install all usable libraries in your virtual environment

Now the project was ready to use just import you images in images folder and change loki.jpg with your filename!
